# 2026-11-16 更新记录

## 本次更新

- 默认入口改为启动 PostgreSQL 协作哈希网页。页面显示远端文件清单、哈希完成状态和部署连通信息，并支持设置单轮任务数量、开始和停止本机工作节点。
- 新增 `distributed_hash.py`，提供 PostgreSQL 队列初始化、SQLite 清单及哈希迁移、状态查看和工作节点命令。工作节点通过任务租约领取数据库中的相对路径，在本机挂载的 SMB 共享读取文件；不遍历 NAS 目录。
- 增加文件元数据清单与已保存清单哈希流程。旧的本地 SQLite 扫描、HTML 报告及其命令行参数仍可通过 `--no-open` 使用。
- 新增 PostgreSQL Compose 部署样例、环境变量模板和部署信息展示模块。页面只展示配置的非敏感信息及 TCP 探测结果，不展示数据库密码。
- 更新 README 和配置示例，补充协作页面默认运行方式、依赖安装、本地扫描回退方式和文档导航。

## 配置与运行

- 默认浏览器协作页面需要安装 `requirements-distributed.txt` 中的 PostgreSQL 驱动。
- 每台工作电脑单独配置私有连接文件 `~/.config/nasdedup/worker.dsn`（Windows 为用户目录下 `.config\\nasdedup\\worker.dsn`），并将 `LOCAL_NAS_WINDOWS` 或 `LOCAL_NAS_MACOS` 设置为本机 SMB 挂载路径。
- PostgreSQL 部署模板位于 `deploy/postgres.compose.yml` 和 `deploy/postgres.env.example`。生产密码、连接串和数据不应提交至仓库。
- 详细部署及迁移步骤见 [分布式哈希说明](DISTRIBUTED_HASHING.md)，Windows 和 MacBook Pro 工作节点步骤见 [工作节点操作手册](WORKER_SETUP_WINDOWS_MACBOOK.md)。

## 验证与后续

- 保留 `--no-open` 本地 SQLite 扫描与报告流程，便于离线或单机使用。
- 分布式运行依赖 NAS PostgreSQL 服务、每台电脑的私有 DSN 和可访问的 SMB 挂载路径；部署及各节点连通性需在目标机器上分别核对。
