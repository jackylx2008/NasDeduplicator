# 2026-11-13 更新记录

## 本次代码同步

- Windows 电脑通过群晖同步了浏览器协作哈希页面：默认入口改为读取 PostgreSQL 的任务总数、完成数和文件列表；用户可设置本轮任务数量、开始计算或请求停止。页面工作时从数据库领取路径，不重新遍历 NAS 共享目录。原本地 SQLite 扫描仍可通过 `--no-open` 使用。
- Mac mini 项目根目录已创建 `.venv`，安装 `requirements-distributed.txt` 中的 `psycopg[binary]`。编辑器使用系统 `python` 启动时，入口脚本在本机 `.venv` 存在的情况下自动切换到它。系统 Python 由 uv 管理，直接运行 `python -m pip install` 会被拒绝，因此不要对系统解释器强制安装。
- 各电脑应使用各自的虚拟环境；Git 忽略 `.venv`，群晖同步也应排除它。浏览器页面连接数据库需要本机私有的 `~/.config/nasdedup/worker.dsn`（Windows 对应用户目录下的 `.config\\nasdedup\\worker.dsn`）；该文件不应放入仓库或共享同步目录。
- 已验证 Mac mini 的虚拟环境可导入 `psycopg`，并且以系统 `python -u nas-deduplicator.py --help` 启动时能够完成虚拟环境切换。实际 PostgreSQL 页面和 Windows 节点运行尚需在对应电脑上验证。

## 功能

- 本地扫描改为三步浏览器流程：选择部分或全量范围、选择是否计算 SHA-256、确认开始。统计阶段写入全部文件的路径、大小和修改时间；哈希阶段可直接从已保存清单取路径，不必再次遍历 NAS 目录。
- 页面显示已统计文件数、总容量、阶段与总耗时，以及“停止扫描并保存”按钮。`#recycle` 等回收站目录默认跳过。SQLite 清单每约 1,000 个文件提交一次，哈希索引每约 100 个文件提交一次。
- HTML 操作页与结果页新增协作服务审核区：显示 DSM 地址、PostgreSQL 端点、配置的数据目录、TCP 连通性与检查时间。此探测只证明端口可达；容器健康和数据库身份认证需另行核验。页面不显示任何密码。
- 各模块工作日志统一写入入口对应的 `logs/nas-deduplicator.log`。结果页树形结构只展示已计算哈希的文件；全量文件元数据在 SQLite `inventory` 表。
